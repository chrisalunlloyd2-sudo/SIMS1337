# SIMS1337 — BACKUP DOCTRINE (for any agent building or modifying)
> Rule: **GitHub main is the source of truth. Local is disposable.**
> Every agent that builds, modifies, or deploys MUST follow this. No exceptions.

## The three laws
1. **BACK UP BEFORE** — snapshot before any modification (branch + tag or tarball).
2. **BACK UP AFTER** — commit + push to main immediately after a successful change.
3. **NEVER DELETE** — ADD only. If something must go, archive it (archives/ or a branch),
   never rm. History is the safety net.

## Every modification cycle
```bash
# 1. Sync + orient
git fetch origin && git pull --ff-only origin main
bash scripts/backup.sh --snapshot "before-<feature>"   # tag + tarball

# 2. Build/modify (never touch files outside your hex/FOW scope)

# 3. Verify (tests MUST pass)
python3 -m pytest tests/ -q 2>/dev/null || echo "no pytest — run targeted tests"

# 4. Commit + push (auto-backup)
bash scripts/backup.sh --push "feat: <what you did>"
#   - stages all changes, commits with a clear message, pushes to main
#   - writes a backup receipt to logs/backup_receipt.jsonl
```

## At ALL times (continuous safety)
- `logs/backup_receipt.jsonl` — every commit/push logged (ts, sha, message, agent)
- `reports/BACKUP_STATUS.md` — regenerated by backup.sh --status: last backup, drift vs origin
- Any agent that finds local ahead of origin by >1 commit MUST push immediately.

## Disaster recovery
```bash
# restore from a snapshot tarball (rollback point)
bash scripts/backup.sh --restore <tag-or-tarball>
# or fresh clone (local lost = fine, GitHub is the truth)
git clone https://github.com/chrisalunlloyd2-sudo/SIMS1337.git
```

## Who must run this
- **Every agent** (CodeAgent, DeployAgent, ResearchAgent, ReviewAgent, SLMAgent)
- **Every pipeline** (hourly issue, interstitial scheduler, deploy, LoRA training)
- **Every human** (Chris — Qwen's builds on device included)

> If a process doesn't know how to back up, it doesn't modify. Full stop.
